IF GROK DISAPPEARS — WHAT TO DO
-------------------------------
You have two paths. Path A is the simple one.

PATH A — Hand this zip to a web person (recommended)
  1. Send them this whole folder.
  2. Tell them: it is a React / TanStack Start site. Run npm install,
     then npm run build. Deploy the build to Vercel, Netlify, or any
     Node host. Point ishs-concessions-and-catering.com at that host.
  3. Give them your domain login so they can change the DNS.
  4. Give them the logo files in public/images/logo-full.png
     and logo-mark.png — those are the originals.

PATH B — Do it yourself on Vercel (free for a site this size)
  1. Create a free account at vercel.com (use your own email, not Grok).
  2. Install Node.js LTS from https://nodejs.org (the “LTS” button).
  3. Unzip this folder. Open Terminal (Mac) or PowerShell (Windows).
  4. Type:  cd  then a space, then drag the unzipped folder in, then Enter.
  5. Type:  npm install
  6. Type:  npm run build
  7. On vercel.com choose Add New → Project → upload this folder
     (or connect a GitHub repo if you make one).
  8. When Vercel gives you a URL, go to your domain registrar and
     point ishs-concessions-and-catering.com at Vercel. Vercel’s
     docs call this “add a domain.” It takes a few hours to stick.

You do not need Grok, WordPress, or this chat for either path.
